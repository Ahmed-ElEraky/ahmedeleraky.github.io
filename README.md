# Ahmed Sayed Farrag Eleraky — Portfolio

Single-file animated portfolio site (aviation engineering / UAV & AI systems).

## Publish it on GitHub Pages (free, gives you a stable CV link)

1. Create a **new GitHub repository** (e.g. `portfolio`, or use `<your-username>.github.io` for the shortest possible URL).
2. Push these files (`index.html`, `hero-photo.jpg`, `.nojekyll`) to the repo's `main` branch, root folder.
3. In the repo: **Settings → Pages → Build and deployment → Source → Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
4. Wait ~1 minute — GitHub gives you the live URL, which is either:
   - `https://<your-username>.github.io/` — if the repo is named exactly `<your-username>.github.io`
   - `https://<your-username>.github.io/portfolio/` — if the repo has any other name (e.g. `portfolio`)
5. (Optional) Add a custom domain under **Settings → Pages → Custom domain** if you own one — cleaner for a CV.

That URL is what goes on your CV/LinkedIn.
